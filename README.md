# Jackfield

An NMOS controller for SMPTE ST 2110 networks.

Jackfield discovers NMOS devices on your local network and lets you configure them —
inspect senders and receivers, and connect them to each other. It runs either as a
terminal UI or as a web server, from the same binary.

Upstream: <https://github.com/st2110/jackfield>
